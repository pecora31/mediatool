# Mediatool

All-in-One Media Downloader & Converter (YouTube, Facebook, X, Images, Audio, Video).

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/pecora31/mediatool)

### Features
- Download videos and audio from YouTube, X, Facebook, and 1000+ sites.
- Convert images (WEBP, PNG, JPG, ICO, BMP, TIFF), audio (MP3, WAV, FLAC, AAC, OGG, M4A), and video (MP4, GIF, WEBM, MKV, AVI, MOV).
- Pure monochrome, clean and fast UI.
- Dual-mode: Local (saves directly to PC) and Cloud (downloads directly to browser).
